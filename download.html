Download & Setup Guide

Get PocketFence running in minutes

Step 1: Download

Clone or download from GitHub:

git clone https://github.com/DJMcClellan1966/PocketFence-Family.git
View on GitHub

Step 2: Prerequisites

Install required software:

  • .NET 8.0 SDK (Download)
  • Windows/Linux/macOS
  • 2GB RAM minimum
  • Port 5000 available

Step 3: Run

Build and start the dashboard:

dotnet build
dotnet run dashboard

Access at: http://localhost:5000
